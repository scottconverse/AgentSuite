The problem

AI IDEs generate well. They remember nothing.

Every new session re-introduces context, re-drifts on voice, and re-argues decisions that were settled last week. AgentSuite is the system around generation: artifacts on disk, QA-scored, versioned, and fed forward.

Without a kernel

"Write our positioning again." A fresh answer, slightly different from last time, lost when the tab closes.

With AgentSuite

Positioning, voice guide, and claims library live in _kernel/<project>/. The next agent, and the next session, start from them.

How a run works

Five stages, one approval gate, then promotion.

Every agent walks the same deterministic pipeline, so the operator's mental model is identical across roles. Nothing is promoted without a human approve step.

01Intake

Collect the goal, constraints, and any input files into a manifest.

02Extract

Pull structured context out of the inputs.

03Spec

Write the primary artifacts: 9 to 10 Markdown and JSON documents per role.

04Execute

Generate the reusable brief-template library for that role.

05QA

Score every artifact against a rubric. Write qa_report.md.

stage: approvalThe run pauses. You read the spec and the QA report. Cost per stage is already in cost_summary.json.
approve ⟶
.agentsuite/_kernel/<slug>/Approved artifacts are promoted here and consumed by every downstream agent and every later session.

Seven agents

What persists

Approved artifacts promote to the kernel and are picked up automatically by the next agent or the next IDE session.

_kernel/<slug>/

The kernel

Written once. Versioned. Reused by everything after.

fsEverything is on diskMarkdown and JSON under .agentsuite/runs/<run-id>/. Diff it, commit it, read it in any editor.
qaEvery artifact is scoredA rubric produces qa_scores.json and a readable report before you approve anything.
$Cost is tracked per stageCapped per run, previewable before approval, reported by agentsuite_cost_report.
⟳Runs resumeInterrupted runs continue from their last completed stage. Resume is idempotent by design (ADR-0007).

Run it

Any provider. Any MCP host. Or no install at all.

Distributed from GitHub only, by decision (ADR-0006). Set one API key, or run a local Ollama daemon and set nothing.

Install with your provider

One optional extra per provider. The resolver auto-detects whichever key is set, and falls back to a local Ollama daemon at localhost:11434.

[anthropic][openai][gemini][ollama] · offline, $0[all]
pip install "agentsuite[anthropic] @ git+https://github.com/scottconverse/AgentSuite.git"

# fully local: pull a Gemma 4 model, then run as usual
ollama pull gemma4:e4b
agentsuite founder run --business-goal "Launch My Product v1" --project-slug mp

Surface the agents as MCP tools

The same package is an MCP server. Agents appear as agentsuite_founder_run, agentsuite_founder_approve, agentsuite_kernel_artifacts and friends inside your IDE.
